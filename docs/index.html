Get your time series ready to forecast.

Nine agents find the time column, choose one series or many to forecast, sort the other columns into past and future covariates, put irregular readings on a fixed grid, measure holiday effects, flag outliers and fill the gaps. Tools measure every fact and rules make every decision. A language model only explains what was found.

Open the app View the code on GitHub

Five steps, nine agents

Each agent runs its tools, decides with fixed rules and hands a cleaner series to the next one. If a check fails, the pipeline stops and tells you why.

  1. 1. Data

    Once per table

    Time Index

    Finds the column that holds timestamps, and the series-id column in long tables.

    • found
    • ambiguous
    • not_found

    Target

    Chooses what to forecast: one value column or several, and one series per id. Future rows without a value become the forecast horizon.

    • single
    • multiple
    • capped

    Covariates

    Sorts every other column into past covariates, future covariates known ahead, static covariates or unused.

    • found
    • none

    Regularity

    Checks for a fixed spacing, including business days and month ends, and counts duplicates and gaps.

    • regular
    • regular_with_gaps
    • irregular

  2. 2. Resampling

    Per series

    Resampling

    Bins irregular readings onto a grid from 1 hour to 1 week and needs at least 30 points to continue.

    • resampled
    • sparse
    • too_few_points

    Frequency

    Names the frequency as a pandas alias and proposes seasonal periods to test, such as 24 and 168 for hourly data.

    • h
    • D
    • W-SUN
    • MS

  3. 3. Holidays

    Per series

    Holidays

    Compares each holiday and the days around it with ordinary days, and adds holiday covariates when they move the series.

    • impact
    • window_impact
    • no_impact

  4. 4. Outliers

    Per series

    Outliers

    Flags values far from the trend and season, skipping holiday days. You keep, remove or replace each one.

    • none_found
    • flagged
    • handled

  5. 5. Missing values

    Per series

    Missing Values

    Fills every empty slot on the grid by interpolation, carrying values forward, zero or the value one season earlier.

    • complete
    • filled
    • long_gaps

One series or fifty. From Regularity on, every agent runs once for each series you forecast. The app shows a combined verdict for the step and lets you pick the series to inspect.

One screen, three panels

Both side panels fold away when you want more room for the chart.

Left panel

Choose a sample or upload a CSV. Turn the language model on or off and see which one is in use.

Centre

The signal path shows where you are. Each step has its settings, a chart of the focus series and a table, and the last step exports every series with its covariates.

Right panel

Ask about the series or change a setting in the chat. Below it, each agent of the step reports its decision, confidence and next step.

How a decision is made

A small model can invent numbers, so it never gets to choose what happens next.

Tools measure

pandas and numpy compute coverage, spacing, gap runs and points per candidate frequency. Every fact is shown with the result.

Rules decide

Fixed thresholds pick the outcome, for example fewer than 30 points stops resampling and suggests a finer frequency.

The model explains

It restates the verdict in plain words from those facts. In the chat it may propose a setting change, which waits until you press Apply.

Run it yourself

The app runs locally, in Docker or as a Hugging Face Space. Nine sample datasets are included, so you can try every agent without your own data.

  • hourly_energy.csvregular hourly
  • irregular_sensor.csvirregular readings
  • daily_sales_with_gaps.csvmissing days
  • 15min_with_duplicates.csvduplicate timestamps
  • business_day_stock.csvbusiness days
  • monthly_passengers.csvmonth starts
  • multi_store_long.csvseveral series
  • daily_sales_holidays.csvholiday effects, outliers
  • store_demand_covariates.csvseveral series, covariates, forecast horizon
# locally, with the CPU model
uv sync --extra llm
uv run python app.py

# or in Docker, on port 7860
docker build -t fcagents .
docker run --rm -p 7860:7860 fcagents
